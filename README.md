A GTA 6 launch-week meme for make.fun's gta6-meme-x-01 bounty. A lone gamer waits out the thirteen years since GTA V on a Vice City beach at sunset, controller in hand, while make.fun's ghost floats beside him: his AI agent already earned the money for the game on make.fun.

The meme is `meme.png` (1024x1024). The post text the meme goes out with is in `POST-TEXT.txt`. `POST.json` holds the X post's address; `main.ts` copies it to the output directory for the house to read.
